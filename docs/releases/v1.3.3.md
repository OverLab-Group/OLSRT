This is a bug-fix release. No public API changes.

## Bug Fixes

- **Actor** — `ol_actor_reply_error` double-free; startup handshake busy-poll (1 ms `usleep`) replaced with a condition variable; missing wake in `ol_actor_start` / `_stop` / `_close`; leaked state cond/mutex in `ol_actor_destroy`.
- **Process** — `_Atomic` mixed with `__atomic_*` casts for `process->state` and `exit_info.reason`; now uses the C11 atomic API throughout.
- **Supervisor** — non-atomic child-ID counter (could collide across supervisors and silently overwrite a child's hashmap entry); restart race with the crash scan (`children_mutex` now held across the whole restart); `child_info_t` and `ol_supervisor_t` shared fields now `_Atomic` (clears all TSan reports).
